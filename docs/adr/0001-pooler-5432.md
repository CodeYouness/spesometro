# 0001 — Session pooler Supabase porta 5432 per ogni connessione

**Contesto:** su Supabase Free la direct connection è IPv6-only e i runner GitHub Actions non hanno IPv6; il transaction pooler 6543 non è adatto a checkpointer LangGraph e Alembic.
**Decisione:** app, Alembic, pg_dump, checkpointer LangGraph (`prepare_threshold=None`, `supports_pipeline=False`) e job su GitHub Actions usano il session pooler porta 5432 (utente `postgres.<ref>`); mai 6543.
**Conseguenze:** una sola stringa di connessione in `.env.example`, con motivazione; `pool_size ≤ 5`, pool chiuso nel cron.
